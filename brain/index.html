KNOWLEDGE WITH RESPONSIBILITY

Useful memory
needs maintenance.

A stored answer is not automatically a correct answer. Each source needs an owner, a date and a rule for who can use it.

We define the approved sources, access boundaries and update process for the job. Conflicting or missing information should be surfaced to a person rather than quietly filled in.
