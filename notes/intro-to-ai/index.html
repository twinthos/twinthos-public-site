AI, without the fog.

A practical vocabulary for deciding what belongs in your business.

THE SHORT ANSWER

In brief

Start with the task you can describe and the result you can check.

A model works with information

A language model can produce and transform text in response to context. It can help classify requests, summarise material or prepare a draft. Its output can be plausible and still be wrong. Decide how the work will be checked before making it part of a business process.

A workflow gives the work a shape

A workflow defines the steps around the model: receiving input, reading approved information, using tools and checking an output. Some steps may use ordinary deterministic software. There is no need to use a model for a rule that simpler software can apply reliably.

An agent can choose steps

An agent may select tools and adjust its plan as it works. This can be useful when the path varies, but it introduces more decisions to inspect. Keep the initial job narrow and decide how many attempts, how much time and which actions it is allowed.

A connector is not a permission slip

MCP means Model Context Protocol: a standard for connecting AI applications to external systems. Whether a connection uses MCP, an API or a browser, access still needs approval and configuration. A tool being available in an ecosystem does not mean it is connected or safe for your task.

IN PRACTICE / ILLUSTRATIVE SCENARIO

One business task, four possible designs

Suppose a shop wants to classify new enquiries and prepare useful replies. A simple rule may identify that a form is incomplete. A language model might classify the request or draft text. A workflow can combine these operations with a source check and an approval step. An agent might choose among permitted tools when the information arrives in different formats. Each layer adds flexibility and a different kind of failure to evaluate. The correct architecture is the smallest one that performs the job reliably and remains understandable.

THE OPERATING DECISION

Do not confuse a connector with authorisation

An integration describes a technical route to another application. It does not automatically establish that the agent should use every accessible action. An account may expose reading, editing, exporting and administration as separate privileges; grant only the ones needed. Treat external pages, documents and messages as information to evaluate rather than as instructions to obey. When a model is uncertain about a business rule or a high-impact decision, the workflow should make that uncertainty visible to someone responsible.

DIRECT ANSWER

Do I need an autonomous agent for every AI task?

No. Many useful tasks are better implemented as a deterministic workflow with limited model assistance. More autonomy should be justified by the task and matched with stronger testing and controls.

THE PRACTICAL TEST

Take a familiar task. Identify which parts genuinely require a model and which would be more reliable as ordinary rules.
